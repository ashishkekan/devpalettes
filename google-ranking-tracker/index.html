How the sample data is produced

Adding a keyword assigns it a random position and creates seven sample history points. These dates are labels for a demonstration, not evidence that the keyword was observed on those days. The relative update times are also simulated. Refresh produces new sample positions; it does not make a Google search request.

A smaller position number represents an improvement in the demonstration. For example, moving from 18 to 9 is an improvement of nine positions, while moving from 9 to 18 is a decline. Random movement here says nothing about a website, an algorithm update or an SEO change.

A short practice exercise

  1. Add three descriptive sample keywords, such as “demo landing page”, “demo color tool” and “demo design guide”. The initial values will differ each time.
  2. Compare each generated position with the dashboard average. A single average can hide differences between individual rows.
  3. Select Top 10. If the list is empty, none of your sample positions meet that filter; switch back to All.
  4. Refresh the sample data and inspect how the change indicator and chart respond. Treat each result as synthetic data.
  5. Export the CSV and open it in a spreadsheet. Label the file as simulated before sharing it with anyone.

Using the simulator controls

Track Keyword adds a keyword with a simulated position. All, Top 10 and Top 50 filter the generated rows, and the search field finds a keyword already in your list. The chart shows generated history. Refresh generates another sample update; the trash control removes a keyword. Export CSV downloads the sample report.

Keep a separate copy if you want to retain an exercise. Browser storage is local to this device and browser; it is not an account backup or a monitoring service.

Where this demonstration is useful

Use the dashboard for a reporting lesson, a spreadsheet exercise or a walkthrough of filters and trend charts. It can help explain the difference between a position, a change and an average without connecting a search account.

Do not use these values for client performance reports, competitor analysis, search visibility claims or business decisions. The tool has no location or device measurement, no live Google results, and no background monitoring or ranking alerts.

How to check actual search performance

For a site you manage, use Google Search Console’s Performance report. It provides observed search clicks, impressions, click-through rate and average position. Choose a consistent date range and review query, page, country and device filters before comparing results.

Average position is an aggregate, not a promise of one fixed position for every searcher. This simulator does not import that report. Keep exported real measurements separate from the synthetic CSV files produced here.

Simulator questions

Does this tool show my actual Google rankings?

No. It assigns random positions and generates sample history for practice. It does not query Google or measure any website.

What does a smaller position number mean?

Within this exercise, a smaller position number is better. A change from 18 to 9 is an improvement of nine positions. The numbers are simulated.

Does refreshing check Google again?

No. Refreshing creates another random sample update. It does not contact Google, run in the background or send ranking alerts.

Can I use the exported CSV in a client report?

Only as a clearly labeled demonstration. The CSV contains synthetic data and must not be presented as measured search performance.
